# TaskNavi の使い方

TaskNavi は、仕事のタスクを「今日やること」「表」「カード」「日程表」「カレンダー」で見られるアプリです。チームの予定は Google ドライブを通して共有できます。

---

## 1. ダウンロードと起動（初めの1回だけ）

1. 次のページを開きます
   **https://github.com/sakamotoryouhei0519-svg/TaskNavi/releases/latest**
2. 「Assets」の中の **`TaskNavi-（数字）-windows.zip`** を押してダウンロードします
3. ダウンロードした zip を右クリック →「すべて展開」→ 展開先を **`C:\TaskNavi`** にして「展開」
   - デスクトップや Google ドライブの中には置かないでください
4. `C:\TaskNavi\TaskNavi` の中の **`TaskNavi.exe`** をダブルクリックします
5. 青い画面で「Windows によって PC が保護されました」と出たら、**「詳細情報」→「実行」** を押します（初めの1回だけです）
6. 次からすぐ開けるよう、`TaskNavi.exe` を右クリック →「送る」→「デスクトップ（ショートカットを作成）」

Java などを別に入れる必要はありません。

---

## 2. 画面の見方

起動すると、いつも「**今日**」の画面から始まります。

| 場所 | あるもの |
|---|---|
| いちばん上 | 「プロジェクト ▼」（自分だけのタスクとチームのプロジェクトの切り替え）、インポート、エクスポート、月のマーク ☾（明るい／暗い画面の切り替え） |
| その下 | 「追加」「削除」「更新」、検索欄、「フィルター ▼」 |
| 真ん中のタブ | 今日 ／ WBS ／ カンバン ／ ガントチャート ／ カレンダー |

どのタブで変えても、ほかのタブにもすぐ反映されます。

### 今日
- 「期限切れ」「今日まで」「7日以内」に分けて出ます。**毎朝ここを見れば十分です**
- 終わったら右の「完了」を押します。行をダブルクリックすると編集できます

### WBS（表）
- プロジェクト → 工程 → タスク の3段で並びます。番号（1、1.1、1.1.1）は自動で付きます
- 左で選ぶと右に詳しく出ます。右の名前をダブルクリックすると編集できます
- 行をドラッグすると、順番や入れる場所を変えられます

### カンバン（カード）
- 「未着手」「進行中」「完了」の3列です。カードをドラッグするか、カードの矢印（← →）で動かします
- 上の「担当者」で人を絞れます。「担当者ごとに分ける」にチェックすると、人ごとにまとまります

### ガントチャート（日程表）
- 開くと今日が真ん中に出ます。土日は色が付いています
- バーの端をドラッグすると期間を、真ん中をドラッグすると日程を動かせます
- Ctrl を押しながらマウスのホイールを回すと、拡大・縮小します

### カレンダー
- 月と週を切り替えられます。日付を押すと、右にその日のタスクが出ます
- 何か月も続くプロジェクトや工程は出さず、その日の作業だけを並べます

## 3. タスクを作る・直す・消す

- **作る**: 「追加」（または Ctrl+N）。種別（プロジェクト／工程／タスク）、親、名前、担当者、開始日、終了日、優先度、状態、メモを入れて「保存」
  - タスクは工程の中に、工程はプロジェクトの中に作ります
- **直す**: タスクをダブルクリック（または選んで Enter）
- **消す**: 選んで「削除」（または Delete）。中のタスクも一緒に消えます。消したすぐ後に出る「元に戻す」で戻せます（10秒間）
- **探す**: 上の検索欄（Ctrl+F）。名前・担当者・メモ・コメントから探します

---

## 4. チームで共有する

チームのプロジェクトは、Google ドライブの共有フォルダを通して全員で同じものを見ます。**パソコンに「Google ドライブ」（Google Drive for desktop）が入っていて、エクスプローラーに G: ドライブが出ていること**が必要です。

### 参加する（メンバー）
1. 代表の人から、プロジェクトのフォルダを Google ドライブで共有してもらいます
2. ブラウザの Google ドライブで「共有アイテム」を開き、そのフォルダを右クリック →「ショートカットを追加」→「マイドライブ」
3. TaskNavi の「プロジェクト ▼」→「**共有フォルダから参加する…**」で、`G:\マイドライブ` の中のそのフォルダを選びます
4. 初めてのときは「表示名」を聞かれます。チームで分かる名前（例: 田中）を入れます。担当者の欄にこの名前が使われます

### 作る（代表の人）
1. 「プロジェクト ▼」→「**＋ 新しい共有プロジェクトを作る…**」
2. できたフォルダを、ブラウザの Google ドライブでメンバーに「編集者」で共有します（見るだけの人は「閲覧者」）

### 使っているとき
- 「プロジェクト ▼」で、自分だけのタスクとチームのプロジェクトを行き来します
- ほかの人の変更は数秒で届きます。上に「メンバー ○人」「同期中」と出ます
- 自分が担当になったときや、自分の担当のタスクにコメントが付いたときは、Windows の通知で知らせます
- 「今日」タブの「**自分の担当だけ**」がオンだと、チームのタスクは自分の担当（と担当なし）だけが出ます
- タスクの編集画面の下で、コメントを書けます
- 2人が同じタスクを同時に変えると、オレンジの「**重なった変更**」が出ます。押すと、どちらの値にするか選べます
- 「プロジェクト ▼」→「変更履歴…」で、誰がいつ何を変えたか見られます。消したタスクもここから戻せます

---

## 5. Excel とのやりとり

- 「**エクスポート**」で CSV に書き出すと、Excel で開いて編集できます
- 「**インポート**」で取り込みます。取り込む前に件数と、取り込めない行（理由つき）が出ます
- 「追加」は今あるタスクに足します。「置き換え」は**今のタスクを全部入れ替える**ので、使う前にエクスポートで控えを取ってください

---

## 6. データについて

- 自分だけのタスクは、このパソコンの中に保存されます。毎日、自動で控え（7日分）を取っています
- アプリを新しい版に入れ替えても、データは消えません
- 新しい版を配られたら、アプリを閉じて `C:\TaskNavi` の中身を新しい zip の中身で置き換え、起動します
- 上に「**アプリの更新が必要**」と出たら、ほかの人が新しい版を使っています。新しい版に入れ替えてください

---

## 7. 困ったとき

| こんなとき | すること |
|---|---|
| 起動しない・エラーが出た | 担当者に連絡してください。エクスプローラーのアドレス欄に `%APPDATA%\TaskNavi\logs` と入れて開き、いちばん新しいファイルを送ってもらうことがあります |
| チームの変更が出てこない | タスクバーの Google ドライブのアイコンが同期中か確かめて、上の「更新」を押します |
| 「共有フォルダを読めません」と出る | Google ドライブにログインしているか、G: ドライブが開けるか確かめます |
| 間違えて消した | 消してすぐなら「元に戻す」。チームのプロジェクトなら「変更履歴…」から戻せます |
| 画面が暗い／明るい | 右上の月のマーク ☾ で切り替えます |
| 英語で表示される | Windows の表示言語に合わせています |
